# Random Forest

This folder contains a Random Forest classification notebook.

## Files

| File | Description |
|---|---|
| `random_forest_classfier.ipynb` | Random Forest classifier workflow using the Titanic dataset from seaborn. |

## Topics Covered

- Loading and exploring the Titanic dataset
- Handling missing values with scikit-learn imputers
- Encoding categorical features
- Splitting data into training and testing sets
- Training a Random Forest classifier
- Evaluating classification performance

## Run the Notebook

From the repository root:

```bash
jupyter notebook
```

Open `Random_forest/random_forest_classfier.ipynb`.

## Dependencies

Install the common notebook dependencies:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn jupyter
```
